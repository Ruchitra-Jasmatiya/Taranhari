## 🌿 About Taranhari

**Taranhari** celebrates the richness of Indian culinary traditions, bringing the warmth of familiar flavours and the charm of traditional delicacies into a beautifully designed digital experience.

Inspired by India's love for authentic snacks and traditional food, the website presents the brand through an inviting visual identity, thoughtful layouts, and an engaging browsing experience.

From the delightful crunch of **Khasta Puri** to the timeless appeal of Indian snacks, Taranhari is designed to make every interaction feel as memorable as the flavours themselves.

> **Our philosophy:** Tradition is not just a taste. It is a feeling we carry with every bite.

## 🎨 Design Philosophy

The Taranhari website embraces a visual direction inspired by traditional Indian food brands.

| Element | Design Direction |
|---|---|
| 🟤 Earthy Brown | Richness, warmth, and heritage |
| 🥛 Cream & Off-White | Clean layouts and visual balance |
| 🌿 Muted Green | Natural accents and freshness |
| ✨ Editorial Typography | A refined, premium brand identity |
| 🍘 Product-Focused Visuals | Making the food the hero |

The goal is simple: **let the product speak, let the design support it, and let the brand create the memory.**

## 💻 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project Folder

```bash
cd my-react-app
```

Replace `my-react-app` with the actual project folder name if it is different.

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Your Browser

Visit the local URL displayed in your terminal, usually:

